# Changelog

## 1.0.0 — 2026-10-03
First public release.
- Global hotkey capture window (default Ctrl+Shift+Space)
- Destinations: daily note, journal types (Journal, Gratitude, Win), tasks, inbox notes
- Attachments by button or drag-and-drop
- Automatic vault, daily note, attachment folder and Tasks plugin detection
- Light, dark and system themes
- Start with Windows option
- `--selftest` diagnostics mode
